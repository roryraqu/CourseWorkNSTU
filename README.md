# Transport Secure System

Гибридное клиентское приложение для управления транспортной логистикой. Сочетает производительность C++ (Qt 6) с гибкостью веб-интерфейсов.

## Архитектура

Система построена на разделении уровней обработки данных и визуализации:

1. **Core (C++):** Высокопроизводительное ядро для работы с сетью, сессиями и криптографией.
2. **UI Layer (WebEngine):** Интерфейс на HTML/JS, работающий в изолированном контейнере Chromium.
3. **Data Layer (Supabase):** Удаленное хранилище данных и REST API.
4. **Network Proxy:** Маршрутизация трафика через промежуточные узлы для защиты топологии бэкенда.

## Технологический стек

* **Языки:** C++17, JavaScript (ES6+).
* **Framework:** Qt 6.x (Network, WebEngine, WebChannel).
* **База данных:** PostgreSQL (via Supabase REST API на собственном VPS).
* **Безопасность:** HMAC-SHA256, SSL/TLS, 2FA (SMTP).
* **Инфраструктура:** Docker.

## Ключевые модули

### 1. Database & Network Manager (C++)

Обеспечивает взаимодействие с внешним API.

* **REST Client:** Инкапсулирует логику запросов к Supabase. Конфигурация эндпоинтов вынесена в `queries.conf`.
* **Auth System:** Реализация двухфакторной аутентификации (пароль + код на почту).
* **Session Guard:** Управление локальными сессиями с проверкой целостности данных по хеш-сумме.
* **Proxy:** Весь трафик идет через зарубежный VPS c распределением нагрузки при помощи nginx.

### 2. Web Bridge (QWebChannel)

Двунаправленный мост между системным кодом и UI.

* **C++ Slots:** Экспонирует методы `login`, `sendMessage`, `requestTickets` в глобальную область видимости JavaScript.
* **JS Callbacks:** Обработка событий завершения сетевых операций и отрисовка данных "на лету".

### 3. Role-Based Access Control (RBAC)

Логика приложения адаптируется под роль авторизованного пользователя:

* **Admin:** Инструменты управления пользователями и корректировки балансов.
* **Manager:** Система обработки входящих тикетов и модерирования контента.
* **User:** Личный кабинет, модуль покупки билетов и чат техподдержки.

## Функционал

* **Ticket System:** Полноценный чат внутри приложения для связи с техподдержкой.
* **Payment Gateway:** Интеграция Stripe для пополнения внутреннего счета.
* **2FA Security:** Генерация и отправка одноразовых кодов доступа через кастомный SMTP-клиент.
* **Dynamic Config:** Настройка параметров подключения через `.env` файлы.

## Развертывание

Проект поставляется в виде Docker-контейнера, содержащего все необходимые зависимости для сборки и запуска среды Qt.

**Сборка образа:**

```
docker build -t transport-app .
```

**Запуск:**

```
docker run -e DISPLAY=$DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix transport-app
```
